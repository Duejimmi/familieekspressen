# Projektgrænse

Dette er et personligt familieprojekt. Brug ikke arbejdsprofiler, Daarbaks designsystem, kundedata eller arbejdsrelaterede skills som grundlag her. Hold dokumentation og fremtidig udvikling i dette repository.

Bevar hjemmesidens eksisterende adresse og funktioner. Publicering sker via en commit-fastlåst bro; undgå ændringer, som bryder den eksisterende URL eller browserens gemte turdata. Bevar localStorage-nøgler ved flytning.
