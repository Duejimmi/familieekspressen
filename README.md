# Familieekspressen

Personligt familieprojekt med fire illustrerede temaer, lokal stemningsmusik, nedtælling og interaktive figurer. Projektet er uafhængigt af Daarbak og arbejdsrelaterede designskills.

## Kode og udvikling

Al udvikling og dokumentation hører til i dette repository. Siden er en selvstændig `index.html` uden byggetrin eller eksterne musikfiler. Åbn den via en lokal HTTP-server ved test.

## Eksisterende adresse

https://duejimmi.github.io/awesome-design-skills/familieekspressen/

Adressen bevares gennem en publiceringsbro i `Duejimmi/awesome-design-skills`. Broen henter en fastlåst commit fra dette repository og lægger siden i Pages-udgivelsens `familieekspressen/`-mappe. Applikationens kildekode skal ikke kopieres tilbage til designrepositoryet.

For at udgive: kontrollér temaer, musik, lydstyrke, timer, indstillinger, stjerner, flytbare figurer og fuldskærm. Opdatér derefter `FAMILY_REF` i publiceringsworkflowet til den godkendte fulde commit-SHA. En ændring på main her udgiver ikke automatisk.

Ved fejl: behold seneste fungerende Pages-udgivelse, eller sæt `FAMILY_REF` tilbage til sidste fungerende version og kør workflowet igen. Slå ikke Pages fra.
